Grace Finance PWA starter package

Contents:
- index.html: app interface
- manifest.webmanifest: install details
- service-worker.js: basic offline caching
- icons/: app icons

To publish free using GitHub Pages:
1. Create/sign in to GitHub.
2. Create a NEW PUBLIC repository (example: grace-finance).
3. Upload all files and folders from this ZIP to the repository root (not the ZIP itself).
4. Repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for the published URL. Open it in Chrome on Android.
8. Chrome menu (⋮) > Install app / Install and create shortcut.

IMPORTANT PRIVACY:
The app currently saves entries in local browser storage on the device. It does NOT cloud-sync to other devices. The public repository exposes the app code, not your locally stored financial entries. Do not enter bank passwords or highly sensitive information. Export a backup regularly.
